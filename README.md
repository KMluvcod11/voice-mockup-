- มือถือ (< 768px): ตาราง 3 คอลัมน์ ของขวัญ | ชิ้น | คูปอง
- กด ▸ ที่วันที่เพื่อเปิด/ปิดรายละเอียดของวันนั้น
- ปุ่มด้านบน: สลับภาษา TH/EN และดูกรณีไม่มีข้อมูล
